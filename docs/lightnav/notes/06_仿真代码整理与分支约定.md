## 论文与实现核对

来源：[论文 v2](https://arxiv.org/html/2608.29896v2)、
[官方代码](https://github.com/EMERGE-Policy/EMERGE-Policy)。
本次官方代码读取版本为 `e4c7134ad2aeb6dded049106ada1c28985b66e69`。
实验室原接入基线为 `9a862bd`；二者不是同一版 API，不能直接复制最新驱动生命周期。
本次没有合并官方 main。

| 论文机制 | 本仓库实现与 LightNav 接入位置 |
| --- | --- |
| Main Agent 维护子目标和完成条件 | `PLAN.md`、导航 workspace skill；每次只传当前导航目标 |
| Operational Skill | `execute_robot_action(action_type="navigate_vln")` |
| 执行与证据回传 | `ACTION.md` → Controller → `SonicLightNavDriver` → `NavigationBackend` |
| 模型作为可调用能力 | JPEG + instruction → 独立 LightNav WebSocket → 局部 waypoint |
| 执行器 | 局部位移/朝向 → SONIC 世界坐标方向 → planner/WBC |
| 结果验证 | `ROBOT_STATE.md` 与 ego observation；模型 stop 不是语义成功 |
| Branch Stack 与记忆 | 由 EMERGE 上层管理；导航驱动不伪造恢复成功或跨任务记忆 |

论文的关键是规划、执行、证据、验证和恢复形成闭环。仅能向模型发请求不等于
完成了框架接入；仅完成导航 tick 也不等于满足子目标。当前补齐了 Agent 工具的
导航动作说明和等待预算，并以离线队列往返测试验证工具到驱动的协议。
尚未重新运行带真实 LLM 的规划、视觉验证和 Branch Stack 恢复闭环。

官方新版本要求 `load_environment/reset_environment/get_scene_catalog/switch_scene`；
实验室版本的 `BaseDriver` 仍使用 `load_scene`。后续升级须单独适配这些接口。

## 本次修复

1. WebSocket 的连接、接收和关闭使用有限超时，登录失败释放 socket；保留 pointing
   输出，支持苹果桌原有的观察辅助逻辑。
2. 模型会话成功后才激活 planner。推理返回时再次检查取消和 runtime，丢弃晚到结果。
3. 导航增加 `max_runtime_s`，默认 120 秒；驱动 `max_action_runtime_s` 默认 120 秒，
   请求不得超过它。`inference_timeout_s` 默认 10 秒，通过 driver JSON 配置。
4. runtime 是同步操作之间检查的预算，不是实时抢占截止点。等待中的模型请求最多
   延迟一个请求超时，之后还需资源关闭；Agent 等待使用 runtime + 60 秒余量。
5. Agent schema 显式列出 `navigate_vln`；保留 `step budget` 与语义成功的区别。
6. 插件包按需导入驱动，独立仿真不加载 EMERGE/tomllib，兼容现有 Python 3.10。
7. 启动器区分 EMERGE 仓库根目录和 `LIGHTNAV_ROOT`，模型权重不会误查到 EMERGE 下。

## 验证与边界

整理前 ProcTHOR 离线基线为 41 项。更新后的结果及命令见 integration README。
本次测试包括本机临时 WebSocket/ZMQ 假服务的真实协议往返、推理期间 stop/reset、
MuJoCo 小场景复位和离线渲染；没有启动真实 LightNav checkpoint、SONIC deployment
或机器人。既有仿真跑通记录来自原项目文档，不能表述为本次重跑通过或量化成功率。

独立苹果桌的 `tabletop_evaluate` 使用仿真真值作离线验收；这些真值不发送给 LightNav。
`LightNav stop=true`、防转圈保护触发和运行预算结束是不同终止原因，不能合并为成功。

## Python 风格

本目录使用 Google 风格：4 空格、80 列目标宽度、导入分组、公共接口采用
Args/Returns/Raises 文档段。格式工具固定为 YAPF 0.43.0，`.style.yapf`
基于 `google`；Ruff 0.14.0 检查基础错误、未使用导入及单行导入排序。
长 URL/字符串等无法合理拆分的内容可超出目标宽度；格式检查不代表 Google
风格指南每一条语义规则都已自动验证。工具装在单独环境，避免污染推理依赖。
